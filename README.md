# 🌊 Endless Runner 2D

An endless running 2D platformer built with **Godot 4**. The game features procedural level generation, dynamic water mechanics, and performance-optimized scene management for mobile devices.

---

## 🛠️ Key Features

- **Infinite Procedural World:** Automatically generates pre-made level chunks ahead of the player while deleting old chunks behind them to maintain smooth performance and minimal memory usage.
- **Global Water Floor:** A single, continuous body of water that seamlessly follows the player across infinite distances without duplicating scenes or breaking physics.
- **Mobile-First Design:** Built specifically for mobile landscape aspect ratios with optimized screen scaling and layout proportions.

---

## 🚀 How to Run

1. Open the project in **Godot 4.x**.
2. Load `MainScene.tscn`.
3. Press **F5** to start playing.
